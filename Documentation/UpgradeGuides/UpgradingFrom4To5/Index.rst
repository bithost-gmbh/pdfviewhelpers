Upgrading from 4.x.x to 5.x.x
=============================

New PDF engine tc-lib-pdf
^^^^^^^^^^^^^^^^^^^^^^^^^
TCPDF and FPDI have been replaced by `tc-lib-pdf <https://github.com/tecnickcom/tc-lib-pdf>`_, the successor of TCPDF.
The ViewHelpers and TypoScript settings stay the same, but the generated documents look slightly different, e.g. line
breaks and spacings might change. Please review the PDF documents you generate.

Custom PDF classes and ViewHelpers
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
``Bithost\Pdfviewhelpers\Model\BasePDF`` now extends ``Com\Tecnick\Pdf\Tcpdf``, all TCPDF and FPDI methods are gone.
If you provide your own PDF class using ``config.class`` or wrote your own ViewHelpers using ``$this->getPDF()``,
you have to migrate them. See :ref:`advanced-customization` for examples. The most important replacements are:

	========================================================== ==================================================================
	TCPDF                                                      BasePDF
	========================================================== ==================================================================
	``__construct($orientation, $unit, $format, ...)``         ``__construct(string $unit = 'mm', bool $subsetFonts = true, string $mode = '')``
	``GetX()``, ``GetY()``, ``SetY()``, ``Ln()``               ``getX()``, ``getY()``, ``setY()``, ``addVerticalSpace()``
	``getPage()``, ``setPage()``                               ``getPageId()``, ``setPageId()``, page ids start at 0
	``AddPage()``                                              ``addPage()`` or ``addPageWithSettings()``
	``SetFont()``, ``setFontSize()``                           ``setFont()``, ``setFontSize()``
	``SetTextColor($r, $g, $b)``                               ``setTextColor('#rrggbb')``
	``setCellHeightRatio()``, ``setFontSpacing()``             ``setLineHeight()``, ``setCharacterSpacing()``
	``MultiCell()``, ``Cell()``                                ``writeText()``
	``writeHTML()``                                            ``writeHtml()``
	``Image()``, ``ImageSVG()``                                ``drawImage()``
	``Line()``, ``Rect()``                                     ``drawLine()``, ``drawRect()``
	``Bookmark()``                                             ``addBookmark()``
	``getAliasNumPage()``, ``getAliasNbPages()``               ``$this->page::PAGE_NUM``, ``$this->page::PAGE_TOT``
	``setSourceFile()``, ``importPage()``, ``useTemplate()``   ``setSourceFile()``, ``importSourcePage()``, ``drawTemplate()``
	========================================================== ==================================================================

``basePdfHeader()`` and ``basePdfFooter()`` are still called on every page, but they are protected now.

Removed settings and arguments
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

* The arguments ``unicode`` and ``encoding`` of the ``DocumentViewHelper`` and the TypoScript settings ``document.unicode``
  and ``document.encoding`` have been removed, documents are always UTF-8 encoded.
* EPS and AI images are not supported anymore, the TypoScript setting ``config.allowedImageTypes.imageEPS`` has been removed.
  Please convert these images to SVG.
* The argument ``absolute`` of the ``GetPosXViewHelper`` has no effect anymore.

PDF/A and PDF/UA
^^^^^^^^^^^^^^^^
``document.pdfa`` creates PDF/A-1b documents as before. ``document.pdfa`` and ``document.pdfua`` can no longer be enabled at
the same time. In PDF/UA mode a document title has to be set.

Fonts
^^^^^
TCPDF shipped many additional fonts, e.g. ``freesans``, ``freeserif``, ``dejavusans`` or ``cid0jp``, which are not included anymore.
Only ``courier``, ``helvetica``, ``symbol``, ``times`` and ``zapfdingbats`` are included. Using another font now throws an
exception "Unknown font", add it with ``config.fonts.addTTFFont`` or switch to one of the included fonts.

Custom fonts configured with ``config.fonts.addTTFFont`` are converted again on first use, the old files generated by TCPDF in
``config.fonts.outputPath`` (``*.php``, ``*.z``, ``*.ctg.z``) can be deleted. Bold and italic variants of custom fonts are
no longer simulated, add them as separate font files, see :ref:`custom-fonts`.

HtmlViewHelper
^^^^^^^^^^^^^^
* CSS units follow the CSS specification, ``1px`` equals ``0.75pt``. TCPDF rendered ``px`` values almost like ``pt``, so
  everything given in ``px`` gets smaller, e.g. font sizes and also attributes without unit like ``<td width="100">``.
  Use ``pt`` or ``mm`` to keep the previous sizes, e.g. ``font-size: 10pt`` or ``width="35mm"``.
* Table headers (``th``) are bold and centered by default like in browsers, use ``text-align`` to change it.
* A ``<br>`` at the end of a block element does not add an empty line anymore, like in browsers.
* Local images must be located within the TYPO3 project. Relative paths are resolved from the directory of the PHP entry
  script, which is the public directory in the frontend, absolute paths are recommended.

Soft hyphens and page number aliases
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
* Soft hyphens (``&shy;``) are only supported in the ``HtmlViewHelper``, use ``autoHyphenation`` for other text.
* The page number aliases of ``GetPageNumberAliasViewHelper`` and ``GetTotalNumberOfPagesAliasViewHelper`` work with all
  fonts in headers and footers. Elsewhere they are only replaced in text using one of the included fonts.

Table of content
^^^^^^^^^^^^^^^^
The table of content is rendered by the extension itself now. In HTML mode the page numbers do not account for another table
of content that is moved in front of it later in the document.
